| 1 | 1 | Base |
| 2 | 2 | 1 + 1 |
| 3 | 4 | 2 + 2 |

Each system has both Universal (U) and Particular (P) terms:
- Universal terms represent general principles
- Particular terms represent specific implementations
- The ratio shifts as systems grow

### 3. Matrix Encoding
